## 1.17.1：钉住拦不住卡片双链（用户反馈「可以用，但是钉住居然阻拦不了卡片这样的双链跳转」）

修法：拦在**手势层**，新增 `blockedByPin()`（true = 已拦下并给提示），三处调用：
- `onNodeClick` 站内链接分支（外链 https/mailto 照常开浏览器）
- `onNodeClick` 的 Alt+单击分支
- `renderBreadcrumb` 的面包屑 click
`openDoc` 保持纯执行不判 pinned（程序性跳转要能过）。新建笔记后钉住时也不跳，
只提示「已建好、未跳转」。
文案同步：setPinned 的 Notice、HELP_ROWS 的「钉住」一行改为
「锁定这张图：切笔记、点双链、点面包屑都不跳转」。

## 讨论（未动工）：缩进包不住引用 / 代码块 / 表格

用户提出：Markdown 的缩进表达不了「节点包含一个引用块/代码块」，但思维导图天然可以。

用 `tmp/parseProbe.ts`（node + esbuild）实测了 7 种写法，现状：
- 多行 `>` → 每行一个**同级**节点（引用边界丢失）；`>` 里的列表 → 拍平成同级。
- `> ```js` → **完全崩**：块识别发生在剥 `>` 之前，碎成 4 个节点。
  → 这是独立于方案选择的真 bug，任何方案落地前都该修（先剥壳再识别块）。
- 代码块/表格在列表下 → 变成「上一个节点」的**子节点**，卡片是占位文案
  （`代码块 · python · 1 行`），且块节点无 src：不能编辑、不能拖、不能加子节点。
- 代码块后跟更深缩进 → 那个缩进被解析成「代码块的子节点」（语法上成立）。

给用户的三个方案（待拍板，勿先实现）：
A 块 = 节点内容（payload，不是子节点）—— 节点行后紧跟、缩进 ≥ 节点的块归属该节点；
B 引用整块 = 一个节点（内部列表不进导图）；
C 引用 = 透明容器（`>` 内列表展开成子节点，要真做嵌套块解析 + 前缀重建）。
建议 A+B，C 缓。
需要用户回答：① 引用里的列表要不要进导图；② 块在卡片里直接展开还是折叠成一行。

## 方案 A 前提被推翻：块不能靠缩进（用户：「这些代码块啥的不能缩进啊」）

`tmp/parseProbe2.ts` + markdown-it 实测，用户的真实笔记是**纯正文顶格**写法
（`13. 项目精读/01. AI项目/deepagents/项目背景.md` 整篇只有一个顶格 ```txt 块）。

硬约束：围栏块只能缩进 **0–3 格**；4 格起就是「缩进代码块」，``` 变字面量
（markdown-it 实测 C 例）。obmind 每层 2 格 → **depth≥2 的节点想用缩进挂块必然 ≥4 格 → 一定坏**。
列表项内是唯一例外（4 格是相对 marker 的内容缩进，实测 D 例正常），但用户不写列表。

顶格块的现状比「归属错」更糟 —— **还会吞掉后面紧跟的缩进节点**：
- case1 `父/  子/```python…` → 块是「父」的兄弟，且 `  下一个子节点` 变成**块的子节点**
- case5 顶格两条 `>` → 两个 depth1 兄弟，第二条吞掉下一个子节点
- case6 顶格表格 → 同上

→ 方案 A 必须改前提：**块按「位置顺序」附着到前一个节点行，完全不看缩进**。
一条规则同时覆盖缩进体系 / 标题体系 / 列表体系；块不参与缩进栈，吞节点的问题随之消失；
拖动时块行原样搬、不用重排缩进。代价：块写错位置不会报错，只悄悄归给上一行。

## 1.18.0：块依附 + callout 容器（用户拍板「整行 + 依附上一个」）

### 块
代码 / 公式 / 表格 / 普通引用都不再是树节点：`attachBlock` 按**位置顺序**挂到「前面最近的
节点行」，卡片里多一行 pill（`obmind-block-pill`，带 hover 预览前 6 行）。归属不看缩进 ——
围栏块只能缩 0–3 格，4 格起退化成缩进代码块，depth≥2 必坏（markdown-it 实测）。
旧版更糟：顶格块会成为「父」的兄弟，并把后面紧跟的缩进节点收养走。现在块不参与缩进栈，
吞节点的问题一起消失。`src.blockStart/blockEnd` 记行区间，move/create/删除都靠它。

### callout
第一版把 `>` 也当普通引用 pill，语料一跑就发现整篇正文被藏起来（10 篇问答笔记全中，
节点数掉到个位数）。改成**容器**：`buildVLines` 把 callout 摊平成虚拟行（每行剥一层 `>`），
标题行成节点、正文按剥后缩进分层；`v.orig/v.off` 保证回写仍落在原行正确位置。
没写标题时用正文第一行顶上，`promoted` 让区域内层级整体上移一层（否则 `1.` / `2.` 那种
大纲会多套一层空壳）。顺带修掉「`> ```js` 碎成四行」（块识别现在发生在引用之后）。

### 写路径跟着改
- `insertBlockPlan`：callout 内的块每行带 `>`，块内空行写成 `>`（否则引用被截断）
- `planCreate`：callout 标题的「同级」落到引用外面、`mark` 不吃 `[!note] `；子级不再缩进
- `moveNode/moveNodes`：`rebaseQuote` 整块换引用前缀（拖进/拖出 callout）
