## Obsidian 插件 Outline Mindmap 实现
- 需求：把当前笔记（根=文件名，正文按空格/Tab 缩进分层）渲染成可交互 SVG 思维导图。
- 技术栈：TypeScript + esbuild（Obsidian 标准骨架）+ markmap-lib / markmap-view（0.18.12）。
- 文件：manifest.json、package.json、tsconfig.json、esbuild.config.mjs、src/parser.ts（缩进→md 纯函数）、src/MindmapView.ts（ItemView + markmap + 实时防抖刷新 + 点击节点跳真实文件）、src/main.ts（ribbon + 命令 + 视图注册）。
- 关键决策：markmap 必须 bundle（不放 external）；实时刷新用 editor-change(防抖300ms) + active-leaf-change；点击节点用 metadataCache.getFirstLinkpathDest 解析真实文件后 openFile。
- 构建：`npm run build` 通过，产出 main.js（1.4MB）。
- 坑：本机 Windows 上 esbuild 后置安装脚本在沙箱内会 EBUSY，必须关闭沙箱（dangerouslyDisableSandbox）才能 npm install / build。
- 待办：在 Obsidian 实测——把 manifest.json + main.js 拷到 `<vault>/.obsidian/plugins/obmind/` 并启用。

## Bug 修复：parser.ts wsMatch[1] not iterable
- 现象：Obsidian 打开导图空白，控制台 `TypeError: wsMatch[1] is not iterable at noteToMarkdown`。
- 原因：正则 `/^[ \t]+/` 无捕获组，`line.match()` 返回的数组 `[1]` 是 undefined；代码却遍历 `wsMatch[1]`。
- 修复：两处 `wsMatch[1]` → `wsMatch[0]`（整段匹配即行首空白）。重新 build + deploy 通过。
- 注意：Obsidian 里本地插件换了 main.js 后需 关闭/重开插件 或重启 Obsidian 才生效。
